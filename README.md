# DS Smart Campus Management System

A Java Swing desktop application for managing campus activities using Data Structures and Algorithms.

## Technologies Used
- Java
- Java Swing
- SQLite
- SQLite JDBC

## Features
- Student Management
- Classroom Management
- Timetable Scheduling
- Library Management
- Attendance Management
- Campus Navigation using Graphs, BFS and DFS
- DS Algorithm Lab for sorting, searching, stacks, queues and hashing

## Requirements
- JDK 21 or compatible Java version
- VS Code or another Java IDE
- SQLite JDBC library

## How to Run
1. Clone or download this repository.
2. Ensure the SQLite JDBC JAR is present in the `lib` folder.
3. Compile the Java source files.
4. Run `campus.Main`.

The application is a Java Swing desktop application. It is not a web application hosted by GitHub Pages.
